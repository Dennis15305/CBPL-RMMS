# История событий из SQL Server

## Экран 030_Events

Источник данных — `RMMS_Demo.rmms.vHaiwellRollEvents`. Время `EventTime`
выводится по Москве; исходное UTC-время остаётся в серверной таблице.

```sql
SELECT TOP (200)
    Id,
    RollNumber,
    Length,
    EventType,
    ShiftNumber,
    EventTime
FROM rmms.vHaiwellRollEvents
ORDER BY Id DESC;
```

Таблица показывает последние 200 событий всей линии. При необходимости
количество строк можно изменить без изменения коллектора или программы ПЛК.

## События выбранного раската за текущую смену

Источник данных — `RMMS_Demo.rmms.vRollEventsCurrentShift`.

Пример для раската 1:

```sql
SELECT
    Id,
    RollNumber,
    Length,
    EventType,
    ShiftNumber,
    EventTime
FROM rmms.vRollEventsCurrentShift
WHERE RollNumber = 1
ORDER BY Id DESC;
```

Число `1` должно заменяться значением внутренней переменной Haiwell,
содержащей выбранный номер раската от 1 до 5.

SQL Server самостоятельно выбирает текущий интервал по московскому времени:

- смена 1 — с 08:00 включительно до 20:00;
- смена 2 — с 20:00 включительно до 08:00 следующего дня.

Ночная смена после полуночи остаётся одним интервалом. Фильтрация только по
`ShiftNumber` не применяется, поэтому события одноимённых смен прошлых дней в
результат не попадают.

## Безопасность

Подключение Haiwell должно иметь только право `SELECT` на используемые
представления. Права изменения таблиц и выполнения записи не выдаются.

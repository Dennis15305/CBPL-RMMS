# Haiwell A10-W — центральная панель ЛГК

Новый проект центральной HMI для системы учёта сырья и готовой продукции линии ЛГК.

## Принятая роль панели

- модель: Haiwell A10-W;
- экран: 10,1 дюйма, 1280×800;
- связь с Schneider Electric TM241CE24T: Modbus TCP по Ethernet;
- основная роль: наблюдение за пятью раскатами, готовым полотном, сменой и состоянием системы;
- команды `Splice` и `Reset` остаются на локальных постах раскатов и не выводятся на центральный экран;
- сервисные команды, если появятся, защищаются отдельным уровнем доступа.

## Состав первой версии

1. `000_Overview` — обзор пяти раскатов и готового полотна.
2. `010_Unwind_Detail` — подробности выбранного раската.
3. `020_Shift_Output` — выпуск за смену, скорость и потери.
4. `030_Events` — завершённые рулоны и состояние очереди передачи.
5. `040_Diagnostics` — ПЛК, RTC, энкодеры, локальные HMI, сборщик данных.
6. `900_Service` — настройки связи и сервисная информация под паролем.

Подробности интерфейса находятся в `SCREEN_SPEC.md`, а предварительная карта обмена — в `TAG_MAP.md`.

## Что требуется перед сборкой проекта в Haiwell Cloud SCADA

- установить официальный Haiwell Cloud SCADA;
- создать проект для A10-W с разрешением 1280×800;
- назначить устройство Schneider Modbus TCP;
- подтвердить IP-адрес ПЛК;
- один раз проверить смещение адресов `%MW` чтением известной сигнатуры;
- добавить и заполнить фиксированную область `GVL_HAIWELL` в проекте ПЛК.

## Текущее ограничение программы ПЛК

В существующем коде уже есть текущая и предыдущая длина пяти рулонов, общий метраж шестого энкодера, скорость линии, смена и очередь событий. Выпуск именно за текущую смену и процент технологических потерь ещё не рассчитаны. Эти два показателя на экране `020_Shift_Output` относятся ко второму этапу расширения ПЛК.

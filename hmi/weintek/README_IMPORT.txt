МАКРОСЫ WEINTEK ДЛЯ НОВОГО ПЛК CBPL-RMMS

Исходные макросы находятся в соседней папке Weintek_Macros и не изменены.

Что изменено:
- команды старого ПЛК через MW41 заменены интерфейсом нового ПЛК MW2360...MW2368;
- номер команды MW2361 формируется из подтвержденного номера MW2330;
- параметры записываются до кода команды MW2360;
- вход оператора передается командой 12;
- останов, переналадка, производство, обед, ППР, ремонт, авария и технология
  переведены на коды нового ПЛК;
- обрыв передается командой 10 с номером Roll, стороной и причиной;
- старые диагностические адреса второго оборудования удалены;
- остаток переналадки читается из MW2321;
- State_Param формирует heartbeat HMI в MW2368.
- State_Param разворачивает 32-битные слова нового ПЛК в Local HMI LW100...LW109.

Локальные значения экрана:
- LW100: номер заказа, 32-bit unsigned;
- LW102: длина текущего заказа, 32-bit unsigned;
- LW104: площадь текущего заказа x100, 32-bit unsigned;
- LW106: длина текущей смены, 32-bit unsigned;
- LW108: площадь текущей смены x100, 32-bit unsigned.
- macro_NewPLC_Display (ID 26) независимо обновляет этот локальный буфер.

Импорт:
1. Сделать резервную копию проекта EasyBuilder Pro.
2. Macro Manager -> выбрать существующий макрос -> Import.
3. Импортировать файл с тем же ID и именем и подтвердить замену.
4. Повторить для всех 15 файлов этой папки.
5. Выполнить Save & Compile каждого импортированного макроса.

Важно:
- macro_Babina только открывает выбор параметров и больше не отправляет команду.
- команду обрыва отправляет Confirm после выбора Roll, стороны и причины.
- прямые адреса объектов экранов этими файлами не меняются.
